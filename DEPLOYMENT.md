# Домашняя бухгалтерия — Инструкция по развёртыванию

## Требования

- Node.js (версия 18 или выше)
- npm (обычно устанавливается вместе с Node.js)

## Установка

1. Клонируйте репозиторий или скопируйте файлы проекта на сервер.

2. Установите зависимости для всего проекта (включая сервер и клиент):

```bash
# Установка в корневой директории проекта
npm install

# Установка зависимостей клиента
cd client && npm install && cd ..
```

## Запуск в режиме разработки

Для локальной разработки с горячей перезагрузкой:

```bash
npm start
```

После запуска:
- Frontend доступен по адресу: http://localhost:5173
- Backend API доступен по адресу: http://localhost:3001

## Запуск на production-сервере

# Для запуска приложения на удалённом сервере выполните:

```bash
npm run start:prod
```

Эта команда:
1. Соберёт клиентскую часть приложения (`npm run build` в папке `client`)
2. Запустит Node.js сервер на порту 3001

После успешного запуска приложение будет доступно по адресу:
```
http://<IP-адрес-вашего-сервера>:3001
```

## Структура портов

| Порт | Назначение |
|------|------------|
| 3001 | Основной порт приложения (API + статика) |
| 5173 | Порт для разработки (только frontend) |

## Управление сервером

Для остановки сервера нажмите `Ctrl+C` в терминале, где запущена команда.

Для постоянной работы сервера рекомендуется использовать:
- **pm2**: `pm2 start npm --name "home-budget" -- run start:prod`
- **systemd**: создать service-файл для автозапуска

## База данных

Данные приложения хранятся в файле `server/database.sqlite`. При первом запуске автоматически создаются необходимые таблицы и добавляются начальные данные (категории расходов, источники доходов).

## Решение проблем

1. **Ошибка "EADDRINUSE: Port in use"**
   - Убедитесь, что порты 3001 и 5173 свободны
   - В Linux/macOS можно освободить порты командами:
     ```bash
     lsof -ti:3001 | xargs kill -9
     lsof -ti:5173 | xargs kill -9
     ```

2. **Изменение порта**
   - Для изменения порта сервера отредактируйте `server/index.js`, изменив значение `PORT`
   - Для изменения порта разработки используйте `npm run dev -- --port <номер_порта>`
