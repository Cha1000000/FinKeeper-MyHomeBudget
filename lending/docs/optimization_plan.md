# План оптимизации и улучшений лендинга FinKeeper24

На основе проведенного аудита (дизайн, техническая часть, SEO), был составлен следующий пошаговый план улучшений. План разбит по приоритетам для последовательного внедрения.

## 🔴 Приоритет P0: Критическая производительность и загрузка

### Шаг 1: Устранение блокировки рендеринга шрифтами (Render-blocking)
- **Проблема**: В `index.css` шрифты загружаются через `@import`, что блокирует парсинг CSS и замедляет отрисовку страницы (FCP).
- **Решение**: Перенести подключение Google Fonts напрямую в `<head>` файла `index.html` через `<link rel="preconnect">` и `<link rel="stylesheet">`. Убрать `@import` из CSS.

### Шаг 2: Оптимизация изображений (WebP)
- **Проблема**: Тяжелые PNG-изображения (суммарно ~4.8 МБ) сильно замедляют загрузку на мобильных устройствах.
- **Решение**: 
  1. Сконвертировать все `*.png` ассеты в `src/assets/` в формат `*.webp`.
  2. Обновить импорты в `App.tsx`.
  3. Добавить атрибут `loading="lazy"` для всех изображений, находящихся ниже первого экрана (below the fold).
  4. Удалить неиспользуемые PNG-файлы.

## 🟡 Приоритет P1: Мобильный UX и Доступность

### Шаг 3: Улучшение Tap-зон и контрастности
- **Проблема**: На мобильных устройствах некоторые интерактивные элементы (кнопки, ссылки платформ) имеют размер менее рекомендуемых 44x44px. Контрастность текста `slate-text` на темном фоне находится на грани допустимого минимума.
- **Решение**:
  1. Добавить `min-h-[44px]` к мобильным кнопкам, ссылкам в футере и компонентам `PlatformLink`.
  2. Слегка осветлить `--color-slate-text` (например, изменить с `#94A3B8` на `#CBD5E1`) для улучшения читаемости мелкого шрифта, либо заменить классы в мелких текстах.

## 🟢 Приоритет P2: SEO и Мета-теги

### Шаг 4: Расширенные Meta-теги (OpenGraph, Twitter)
- **Проблема**: Отсутствуют теги для красивого отображения ссылок в соцсетях и мессенджерах (Telegram, WhatsApp, VK).
- **Решение**: Добавить в `index.html` теги OpenGraph (`og:title`, `og:description`, `og:image`, `og:url`) и Twitter Cards. Добавить базовые SEO-ключи.

## 🔵 Приоритет P3: Технический долг и Архитектура

### Шаг 5: Рефакторинг App.tsx (Компонентизация)
- **Проблема**: `App.tsx` содержит более 1300 строк кода, смешивая анимации, данные и верстку всех секций. Это затрудняет поддержку.
- **Решение**: Разбить лендинг на доменные компоненты:
  - `src/components/Hero.tsx`
  - `src/components/Features.tsx`
  - `src/components/PlatformSection.tsx`
  - `src/components/Testimonials.tsx`
  - `src/components/FAQ.tsx`
  - `src/components/Footer.tsx`
  - Вынести константы (FAQ, отзывы, шаги) в `src/data/landingData.ts`.
