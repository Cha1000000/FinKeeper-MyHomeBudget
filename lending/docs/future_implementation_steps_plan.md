## 🔍 Что можно улучшить (по рекомендациям из статей)

### 1. **Блок проблемы/боли** (отсутствует)

Сейчас лендинг сразу переходит к решению. По данным статей, блок «это про меня» повышает конверсию.

**Рекомендация:** Добавить после Hero секцию типа:

> «Знакомо? Траты теряются, к концу месяца деньги исчезают, а цели откладываются на потом»

### 2. **Социальные доказательства** (слабо)

Сейчас: только иконки «100% приватность», «Рейтинг 4.9+», «Без рекламы»

**Рекомендация:**

- Реальные отзывы (с именем, городом, суммой экономии)
- Кейсы: «Анна сэкономила 45 000 ₽ за 3 месяца»
- Логотипы платформ (RuStore, GitHub)
- Число пользователей («10 000+ пользователей»)

### 3. **Гарантии и доверие** (недостаточно)

Сейчас: только блок о приватности

**Рекомендация:**

- Явное упоминание: «Можно удалить аккаунт в любой момент + выгрузка данных»
- «Нет привязки карты» (уже есть в FAQ)
- SSL/HTTPS бейдж
- Контакты поддержки

### 4. **Открытые цены** ✅

Уже есть — это хорошо! 199 ₽/мес — прозрачно.

### 5. **CTA-кнопки** (можно усилить)

Сейчас: «Начать планирование бюджета», «Загрузить приложение»

**Рекомендация:**

- Добавить конкретики: «Начать бесплатно → Первые 30 дней PRO за 0 ₽»
- Триггеры срочности: «14 дней PRO в подарок»

### 6. **Форма захвата** (отсутствует)

Сейчас: только ссылки на приложения

**Рекомендация:**

- Добавить email-форму: «Получить гайд по бюджетированию»
- Или: «Попробовать PRO 14 дней бесплатно» (2 поля: email + пароль)

### 7. **Мобильная оптимизация**

Нужно проверить:

- Скорость загрузки (Lighthouse)
- Размер изображений (WebP?)
- Tap-зоны кнопок (мин. 44px)

### 8. **SEO-элементы** (отсутствуют)

- Meta title/description
- H1-H3 иерархия (проверить)
- [Schema.org](http://schema.org/) разметка (Product, FAQPage)
