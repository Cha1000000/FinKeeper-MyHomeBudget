# Бриф проекта: лендинг для FinKeeper: Моя домашняя бухгалтерия
**Роль:** Senior Creative Technologist и Lead Frontend Engineer  
**Цель:** Спроектировать современный, технологичный и притягивающий взгляд лендинг для приложения ведения домашней бухгалтерии FinKeeper. Лендинг должен вызывать доверие, ощущение контроля над финансами и премиальности.  
**Эстетическая идентичность:** "Финансовая независимость и контроль".

---

## 1. СТРУКТУРА И КОНТЕНТ ЛЕНДИНГА

Лендинг должен содержать понятное, интересное и заманчивое описание приложения, которое покажет пользователям, как FinKeeper заменит им устаревшие таблицы Excel и поможет взять финансы под контроль.

### Ключевые секции:
1. **Hero-секция:** Захватывающий заголовок, краткое описание (например: "Ваши финансы как на ладони"), презентация интерфейсов приложения.
2. **Основные возможности (Преимущества):** 
   * Учет доходов и расходов с бюджетированием по месяцам.
   * Умные "Копилки" для достижения целей (с автоматическим вычетом из бюджета).
   * Наглядная аналитика, графики трендов и dashboard.
   * Работа без интернета (offline-first синхронизация).

## 2. ОСНОВНАЯ ДИЗАЙН-СИСТЕМА (FinTech & Glassmorphism)

Приложение FinKeeper использует Glassmorphism и Emerald gradient тему. Лендинг должен визуально продолжать этот стиль.

### Палитра
| Элемент | Цвет | Hex | Описание |
| :--- | :--- | :--- | :--- |
| **Основной фон** | Deep Navy | `#141E3A` | Глубокий темный фон для современного "дорогого" контраста. |
| **Акцент (Успех/Рост)** | Emerald Green | `#10B981` | Фирменный цвет FinKeeper. Для кнопок, иконок и акцентов. |
| **Градиентный акцент** | Emerald Glow | `#047857` | Для создания свечения под стеклом (glassmorphism эффект). |
| **Второстепенный текст**| Slate | `#94A3B8` | Дополнительная типографика и описания фич. |
| **Основной текст** | Pure White | `#FFFFFF` | Заголовки и важный текст. |
| **Вспышка (Расходы)** | Rose | `#C73850` | Индикация расходов или лимитов бюджета. |

### Типографика (с учетом кириллицы)
* **Дисплей/Хиро:** `Unbounded` (или `Manrope`) — современный, геометрический гротеск. Придает технологичный, уверенный и "взрослый" вид заголовкам.
* **Интерфейс/Текст:** `Inter` (или `Onest`) — идеален для UI и читаемости объемных текстов с описаниями функций. Холодно и точно.
* **Суммы и бейджи:** `JetBrains Mono` — моноширинный шрифт для финансовых сумм, чисел и системных лейблов. Размер `11–13px`, капс.

### Визуальная фактура
* **Глобальный стиль (Glassmorphism):** Полупрозрачные карточки с фильтром `backdrop-filter: blur(16px)` и легкой светящейся рамкой `border 1px solid rgba(255, 255, 255, 0.1)`.
* **Свечение (Aurora glow):** Мягкие, размытые фоновые градиентные "кляксы" (Emerald/Teal) позади основных UI карточек, придающие объем.
* **Скругления:** Мягкие и современные формы, в основном `border-radius: 16px` или `24px`. Никакого брутализма из прошлых брифов.

## 3. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

* **Стек:** React 19, Tailwind CSS, GSAP 3 (ScrollTrigger) или Framer Motion, Lucide React (для иконок).
* **Микро-интеракции:** Плавный hover на карточках (проявление emerald-свечения, небольшой сдвиг `transform: translateY(-4px)`). Анимированные переходы на кнопках.
* **Философия скролла:** Элементы аккуратно появляются (Fade In + Slide Up) при входе в viewport (через ScrollTrigger). Фоновые градиенты плавно дышат.
* **Качество кода:** Продуманная семантика, адаптивная сетка (mobile-first), ленивая загрузка изображений. Все элементы грида заполнены реальным смыслом без "рыбного" текста.

> **Директива исполнения:** Лендинг должен ощущаться как дверь в технологичный финансовый премиум-продукт. Дизайн обязан транслировать надежность, контроль и передовые технологии финтеха. Ставка на чистые, воздушные (clean) интерфейсы с эффектом левитации панелей.
