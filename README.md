# Обзор проекта "Домашняя бухгалтерия" (FinKeeper)

## Идея и назначение
SPA для учета доходов, расходов, лимитов бюджета по категориям и накоплений (“копилок”), с аналитикой за месяц и трендами по 6 месяцам.

## Архитектура и запуск
- Монорепозиторий: `client/` (React + Vite) и `server/` (Express + SQLite).
- Корневые скрипты запускают оба процесса одновременно (`npm start`).

## Backend (сервер, данные, API)
- Стек: Express, SQLite (better-sqlite3), JWT, bcrypt.
- Порт: `3002`. В проде сервер отдает статические файлы `client/dist`.
- Авторизация: регистрация/логин с хешированием паролей и JWT, токен хранится на клиенте.
- Резервные копии: при логине/проверке токена и вручную — снапшоты данных пользователя, доступен восстановитель.
- Схема БД (ключевые таблицы):
  1. `users`, `categories`, `income_sources`
  2. `months`, `incomes`, `expenses`
  3. `budgets`
  4. `savings_goals`, `savings_transactions`
  5. `user_backups`
- Логика копилок: при пополнении создается “скрытый” расход в категории “Пополнение копилки” (категория скрыта `is_active = 0`), чтобы вклад в копилки снижал доступный баланс месяца.

## Frontend (страницы и состояние)
- Роутинг и защита: защищенные маршруты под `RequireAuth`, публичный `/login`.
- Глобальная авторизация и UI-настройки в `AuthContext` (например, автосворачивание сайдбара).
- API слой: Axios с `Authorization` заголовком, типы сущностей и методы всех endpoints.
- Основные страницы:
  1. `Dashboard` — сводка месяца, тренды, диаграммы структуры расходов.
  2. `MonthView` — ядро учета: доходы/расходы, добавление, правки, лимиты, перетаскивание групп категорий, подтверждение новых источников дохода.
  3. `Categories` — управление категориями расходов и источниками доходов.
  4. `Savings` — копилки, цели, пополнение/снятие, прогресс.
  5. `Settings` — смена имени/пароля, бэкапы, UI-настройки.
- Общий layout/навигация: левый сайдбар, мобильная нижняя навигация, расчет “Доступно” и “Всего активов”.
- Утилиты форматирования: денежный формат RUB и формат дат.

## Потоки данных и логика
- Клиент → API: все операции через `/api/*` с JWT.
- Месяцы: `ensureMonth` гарантирует наличие записи месяца, затем через `month_id` идёт загрузка доходов, расходов, лимитов.
- Аналитика: тренд по 6 последним месяцам и месячная сводка (доходы/расходы/накопления/баланс).
