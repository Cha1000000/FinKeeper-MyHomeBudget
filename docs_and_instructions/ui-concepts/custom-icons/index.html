Авторская система иконок FinKeeper24

Без compose.materialIconsExtended, эмодзи и текстовых спецсимволов · Единый стиль Liquid Glass (Canvas KMP)

Уровень 1 Объёмные стеклянные иконки (18–32dp+)

IconScheduleGlass

Вместо «🕐» и «⏳»

Матовый циферблат с бликом и золотыми стрелками для плановых и авто-операций.

IconFixedCalendarGlass

Вместо «📅»

Стеклянный календарь с изумрудной шапкой и стрелкой цикла для регулярных платежей.

IconManualConfirmGlass

Вместо «✋»

Янтарный стеклянный жетон с ладонью для бейджа «вручную».

IconServerNodeGlass

Вместо «⚙»

Стеклянные серверные модули с индикаторами статуса для «Настройки сервера».

IconInfoGlass

Вместо Material Icons.Outlined.Info

Полупрозрачный жетон с бликом для подсказки «Как считается лимит».

IconLimitsGaugeGlass

Для кнопки «Лимиты»

Две шкалы лимитов с изумрудным и янтарным стеклянными бегунками.

Уровень 2 Компактные авторские глифы действий (14–22dp, в геометрии NavIcons)

IconEditPen

Вместо текстового «✍︎»

Стильное перо с мягкой стеклянной заливкой корпуса и опорной линией.

IconTrash

Вместо «✕» на удалении

Отдельная корзина со стеклянной заливкой — сразу понятно, что действие удаляет запись.

IconCloseCross

Вместо «✕» на отмене / закрытии

Закруглённый крестик в мягком круге для отмены правки и закрытия окон.

IconChevronLeft / Right

Вместо «◀» и «▶»

Мягкие круглые кнопки с шевронами для переключения месяца.

IconExpandChevron

Вместо «▾», «▸», «▼», Material ExpandMore

Единый плавный шеврон раскрытия с анимацией поворота.

IconDragGrip

Вместо текста «Перетащить»

Тактильная стеклянная рукоятка 2×3 вместо громоздкой текстовой кнопки.

IconPlus

Вместо текста «+» на FAB

Фирменный плюс с мягким ореолом для кнопки «Добавить».

IconEyeToggle

Для полей пароля

Переключатель показа/скрытия пароля со стеклянной радужкой и бликом.

IconCheckMark

Вместо текстового «✓»

Галочка в стеклянном жетоне для подтверждений и выбранных чипов.
