# Документация, планы и инструкции FinKeeper24

## Структура

- **`guides/`** — рабочие инструкции: развёртывание (`DEPLOYMENT.md`), руководство по приложению (`walkthrough.md`).
- **`reference/`** — описания текущего состояния системы: синхронизация клиентов, общее состояние реализации, production-готовность и аудит.
- **`adr/`** — Architecture Decision Records (значимые архитектурные решения).
- **`plans/`** — **активные** планы (запланировано или в работе):
  - `db_relocation_out_of_deploy_plan.md` — вынос боевой БД из деплой-директории (отложено);
  - `product_onboarding_web_kmp_plan.md` — продуктовый onboarding (security-часть сделана, остальное — уточнить статус).
- **`plans/archive/`** — реализованные планы (история): запланированные расходы и прогноз месяца (v2.2.0), тёмная тема, AUR-автопубликация, StartupWMClass в deb/rpm, recoverability UX.

## Правила

- Новые планы фич — в `plans/`, после реализации переносить в `plans/archive/`.
- Документы в `reference/` обновлять при значимых изменениях соответствующих подсистем.
