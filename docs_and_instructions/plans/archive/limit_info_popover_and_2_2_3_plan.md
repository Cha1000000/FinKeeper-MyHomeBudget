## 2. Подсказка на плашке «Лимит трат»

### Проблема

После пополнения копилки «Использовано лимита» становится больше суммы расходов
месяца, а остаток может уйти в 0 ₽. Пользователь, не зная, что пополнения копилок
вычитаются из лимита, не понимает, откуда разница.

### Решение (одинаково для обеих платформ)

Рядом с заголовком плашки — маленький круглый значок «i» в цвет плашки
(приглушённый). Нажатие открывает поповер-пузырь, привязанный к значку
(не модальное окно). Значок виден всегда, пока видна плашка.

Содержимое поповера:

```
ⓘ Как считается лимит

Пополнения копилок тоже тратят лимит месяца: деньги откладываются
из того же бюджета, поэтому сумма пополнения вычитается из остатка.

Расходы                 2 000 ₽      ← только если пополнения > 0
Пополнения копилок      1 000 ₽
──────────────────────────────
Использовано лимита     3 000 ₽
```

Разбивка показывается, только если в месяце были пополнения. Без них она
ничего не объясняет.

Цифры берутся из уже посчитанных значений, новых запросов нет:
- «Расходы» = видимые расходы (без «Пополнения копилки»): веб `totalExpense`,
  KMP `state.totalExpense`;
- «Пополнения копилок» = `totalAllExpenses − totalExpense`;
- «Использовано лимита» = `totalAllExpenses` (то же число, что уже на плашке).

### Web — `client/src/pages/MonthView.tsx` (плашка ~строка 784)

- Кнопка `<button type="button">` с иконкой `Info` (lucide-react, 14–16px) сразу
  после текста «Лимит трат на месяц»; `aria-label="Как считается лимит"`,
  `aria-expanded`.
- Вся плашка кликабельна (открывает диалог лимитов), поэтому клик по значку и
  по поповеру вызывает `e.stopPropagation()`, чтобы диалог не открывался.
- Поповер — по образцу уже существующего меню «Действия» в этом файле:
  прозрачный `fixed inset-0` слой для закрытия кликом мимо + `absolute`
  карточка `bg-[var(--color-surface)]`, `rounded-2xl`, та же тень и рамка,
  `z-40`. Ширина `w-72 max-w-[calc(100vw-2rem)]`, чтобы не вылезать за экран
  на телефоне. Закрытие ещё и по `Esc`.
- Цвета — через существующие токены темы, чтобы работали светлая и тёмная темы.
- Состояние — один `useState<boolean>` в компоненте.

### KMP — `ui/screens/MonthViewScreen.kt` (плашка ~строки 222–255) + `ui/Strings.kt`

- В `Row` заголовка: `Text(SPENDING_LIMIT)` + `IconButton` с
  `Icons.Outlined.Info` (иконка ~16dp, зона нажатия ~32–40dp), тинт —
  `semantic.warningColor` с альфой 0.7. Справа, как и сейчас, «X / Y».
- Поповер — `Popup` (compose-ui), привязанный к значку, с
  `PopupProperties(focusable = true)`: закрывается тапом мимо и кнопкой «Назад»
  (Android) / `Esc` (desktop). Внутри — `GlassyCard` в стиле приложения с
  текстом и разбивкой, ширина ~280dp.
- Штатный `RichTooltip` не беру: Material3 1.2.1 в CMP 1.6.10 — экспериментальное
  API, и поведение показа по клику на десктопе не проверено. `Popup` предсказуем
  на всех платформах.
- Разметку поповера вынести в отдельный `@Composable private fun
  LimitInfoPopup(...)`, чтобы плашка не разрасталась.
- Новые строки в `Strings.kt`: `LIMIT_INFO_TITLE`, `LIMIT_INFO_TEXT`,
  `LIMIT_INFO_EXPENSES`, `LIMIT_INFO_SAVINGS`, `LIMIT_INFO_USED`,
  `LIMIT_INFO_BUTTON` (для `contentDescription`).
