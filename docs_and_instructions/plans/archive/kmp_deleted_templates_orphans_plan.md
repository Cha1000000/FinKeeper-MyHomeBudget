# KMP: удалённые категории/источники — не терять связь записей с ними

Дата: 2026-09-22 · Платформа: KMP · Выпуск в составе 2.2.3 · Сервер и веб не меняются

## Проблема (подтверждена кодом, песочницей и эмулятором)

Сервер удаляет категорию/источник **мягко** (`is_active = 0`) и пишет tombstone
(`deleted_records`). KMP применяет tombstone **физическим удалением** локальной строки
(`SyncManager.applyDeletedRecord`, ветки CATEGORY и INCOME_SOURCE).

- **Категории** (последствие фикса `include_inactive` из 2.2.3): синхронизация возвращает
  удалённую категорию как неактивную, но под **новым локальным id**; старые расходы ссылаются
  на удалённый id → группа «Без категории» (суммы верные).
- **Источники доходов** (было и раньше): доходы удалённого источника ссылаются на удалённый
  локальный id, описания нет → вместо названия выводится число-id.

Внешние ключи SQLite не включены → `ON DELETE CASCADE` не срабатывает, записи остаются
«сиротами».

## Решение

1. **Tombstone = деактивация, не удаление.** В `applyDeletedRecord` для CATEGORY и
   INCOME_SOURCE — `isActive = 0` с сохранением id (как на сервере). UI и план-слой
   неактивные уже отфильтровывают.
2. **Источники доходов — с неактивными:** `ApiClient.getIncomeSources()` →
   `/income_sources?include_inactive=1` (сервер поддерживает). Проверить, что UI везде
   фильтрует `isActive` у источников.
3. **Починка уже «осиротевших» записей у существующих пользователей** (при обычной
   синхронизации, без миграции):
   - расходы: если у синхронизированного расхода `categoryId` ≠ локальный id категории,
     найденный по серверному `category_id`, — перезаписываем, даже если сама запись на
     сервере не менялась;
   - доходы: если `incomeSourceId` указывает на несуществующий локальный источник —
     пересопоставляем по имени (как при обычной синхронизации).

## Проверка

- Unit/desktop-тесты зелёные.
- Песочница: уже есть «сирота» (расход 500 ₽ удалённой категории в «Без категории») →
  после синхронизации группа называется «Необходимое в квартиру», суммы те же.
- Удалить на сервере источник с доходом → в KMP доход с прежним названием, сумма та же;
  источник не появляется в выборе источника.
- Эмулятор — то же визуально.
