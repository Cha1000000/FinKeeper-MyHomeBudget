# Руководство по приложению "Домашняя Бухгалтерия"

Приложение успешно установлено и настроено. Ниже приведена инструкция по запуску и использованию.

## Как запустить

Для работы приложения необходимо запустить сервер (Backend) и клиент (Frontend).

1. **Сервер** (в отдельном терминале):
   ```bash
   cd server
   node index.js
   ```
   Сервер запустится на порту `3001` и подключится к базе данных `database.sqlite` (автоматически создана в папке server).

2. **Клиент** (в отдельном терминале):
   ```bash
   cd client
   npm run dev
   ```
   Клиент будет доступен в браузере (обычно по адресу http://localhost:5173).

## Основные Функции

### 1. Обзор / Дашборд
- **Сводка**: Карточки с текущим доходом, расходом, балансом и накоплениями за текущий месяц.
- **Динамика**: График (столбчатый) сравнения доходов и расходов за последние 6 месяцев (автоматически собирается из введенных данных).
- **Структура**: Круговая диаграмма распределения расходов по категориям за текущий месяц.

### 2. Месяц (Операции)
Это основной раздел для ведения учета.
- **Переключение месяцев**: Кнопками влево/вправо в заголовке.
- **Вкладки**: Доходы / Расходы.
- **Добавление**: Кнопка "+ Добавить" открывает форму.
  - *Доход*: Укажите сумму и источник.
  - *Расход*: Укажите сумму, категорию и комментарий.
- **Лимиты (Бюджет)**:
  - Нажмите на карточку "Лимит на месяц" (или синюю карточку в сводке) чтобы открыть **Настройку Бюджета**.
  - Установите плановые лимиты для каждой категории на текущий месяц.
  - Дашборд покажет прогресс-баром, насколько вы укладываетесь в общий лимит.

### 3. Категории
- Список всех доступных категорий расходов.
- **Добавление**: Кнопка "Новая категория".
- **Редактирование**: Кнопка "Карандаш" (переименование).
- **Удаление**: Кнопка "Корзина" (скрывает категорию).

### 4. Копилки (Накопления)
- Создавайте цели накоплений (например, "Отпуск").
- В каждой копилке есть прогресс-бар (Текущая сумма / Цель).
- Кнопки **Пополнить** и **Снять** позволяют вносить изменения в баланс копилки. Эти операции также учитываются в статистике месяца.

## Технические Детали
- **База Данных**: SQLite (`server/database.sqlite`). Файл можно скопировать для резервного копирования.
- **Стек**: React, TypeScript, Tailwind CSS, Recharts, Node.js, Express.
